# DjanGo 
- it's a backend framework
- it uses the MVT (Model View Template)

## FrameWork 
- collection of modules, packages and libraries to speed up the development process
- pre-defined structure or template for development
- DjnaGo REST frameWork: to build API's
- some more python based frameworks: flask (lightweight), cherryPie, web2py, pyramid
